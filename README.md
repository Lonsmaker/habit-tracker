# ✅ Трекер привычек

Веб-приложение для отслеживания ежедневных привычек с прогрессом, статистикой и архивом. Создан с помощью вайб-кодинга — генерации веб-приложений через AI-инструменты.

## 🎯 Функционал

- **Добавление и редактирование привычек** — с выбором дней недели
- **Отметка выполнения** — прогресс в процентах, счётчик «выполнено / всего»
- **Сводка за неделю**:
  - Лучший день по продуктивности
  - Среднее количество привычек в день
  - Общий итог за неделю
- **Архивация** — перенос привычек в архив, фильтрация «активные / архив»
- **История выполнения** — раскрывающийся список по каждой привычке
- **Смена фона** — переключение оформления приложения
- **Очистка за сегодня** — сброс всех отметок за текущий день одним кликом

## 🛠 Технологии

- HTML5
- CSS3 (Flexbox, Grid, переменные для тем)
- JavaScript (vanilla, без библиотек)

## 🚀 Как запустить

1. Скачайте файлы репозитория
2. Откройте `index.html` в браузере
